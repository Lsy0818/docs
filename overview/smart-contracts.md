# Smart Contracts

Rocky runs on the **Canton Network**. Core exchange logic — margin locking, position updates, and settlement — is implemented as **DAML smart contracts**, paired with a high-performance off-chain execution layer for order matching.

## On-chain components

* **Margin & positions** — DAML contracts lock collateral and record every position update.
* **Settlement** — atomic, private, Canton-native settlement for each trade.
* **Asset workflows** — protocol-level control over asset movement and financial workflows.
